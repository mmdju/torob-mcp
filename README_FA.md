# torob-mcp

سرور MCP برای [ترب](https://torob.com)، موتور مقایسهٔ قیمت ایران.
فقط‌خواندنی، بدون کلید API.

کد در ریپوی خصوصی `mmdju/torob-mcp-private` است. این ریپو نسخهٔ عمومی و
فقط‌داکس است: مرجع ابزارها، معماری و نمونه‌ها — بدون هیچ کدی.

- [مرجع ابزارها](docs/tools.md)
- [معماری](docs/architecture.md)

## چه کار می‌کند

ترب قیمت یک محصول را از ده‌ها فروشگاه جمع می‌کند. این سرویس همان داده را پشت
چند ابزار ساده می‌گذارد تا یک عامل بتواند بپرسد «این کجا ارزان‌تر است و آن
فروشگاه قابل‌اعتماد است؟» — بدون اینکه حتی یک صفحه را بخزاند.

| ابزار | برای چه |
|---|---|
| `torob_suggest` | تبدیل حرف‌های خودکار به عبارت‌های واقعی جستجو |
| `search_products` | جستجو با کارت‌های فشرده (ارزان‌ترین پیشنهاد به تومان) |
| `product_details` | یک محصول به‌همراه همهٔ فروشنده‌ها، امتیاز و رأی هر فروشگاه |
| `compare_products` | مقایسهٔ ۲ تا ۵ محصول کنار هم |
| `find_best_value` | «بهترین زیر بودجهٔ X» |

## اتصال سریع

```json
{
  "mcpServers": {
    "torob": { "url": "https://torob-mcp.mmdju.workers.dev/mcp" }
  }
}
```

نمونه‌های Claude Desktop و Cursor در [examples/mcp.json](examples/mcp.json) است.
چیزی برای نصب نیست و کلیدی هم لازم نیست: آدرس عمومی است و فقط می‌خواند.

## مرزهای صادقانه

- قیمت‌ها مدام عوض می‌شوند — هر محصول لینک ترب خودش را دارد تا کاربر خودش
  تأیید کند.
- کارت جستجو فقط **ارزان‌ترین** پیشنهاد را نشان می‌دهد؛ برای دیدن همهٔ فروشنده‌ها
  `product_details` لازم است.
- قیمت صفر یعنی ناموجود، نه رایگان.
- اگر پیام `price_unreliable` دیدید، خودِ ترب هشدار داده که آن قیمت قابل‌اعتماد نیست.
- این سرویس وابسته به ترب نیست و توسط آن تأیید نشده است.
